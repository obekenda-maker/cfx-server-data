# [esx]

Hier komen de ESX-resources die de server nodig heeft (zie `server.cfg.example`): `esx_menu_*`, `skinchanger`, `esx_skin`,
`esx_identity`, `esx_addonaccount`, `esx_addoninventory`, `esx_datastore`, `esx_society`, `esx_status`, `esx_basicneeds`, `esx_license`.
Installeer **niet** `esx_ambulancejob`, `esx_policejob`, `esx_mechanicjob`, `esx_vehicleshop`, `esx_shops` of `esx_weaponshop`:
`rp_jobs`, `rp_garages` en `rp_shops` vervangen ze en zouden anders dubbele systemen/dood-afhandeling geven.
